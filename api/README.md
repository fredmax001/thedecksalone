# Backend API (`app/api`)

Express 5 + TypeScript + Prisma + PostgreSQL backend powering the Deck Salone platform, REST APIs, real-time SSE notifications, scheduled jobs, media/upload gating, and SPA SSR meta-tag injection. Part of the workspace app (see [app/README.md](../README.md)).

## Key Files

| File | Responsibility |
| --- | --- |
| `server.ts` | Main Express entrypoint (defaults to `PORT \|\| 5000`; `.env.example` sets `5002`). Loads `app/.env` then `app/api/.env` overrides; wires Helmet, strict CORS, `cookie-parser` (OAuth state), 1 MB JSON/URL-encoded parsers, gzip, `X-Request-Id` + Prometheus histograms, Passport, gated `/uploads`, health/metrics/image-proxy/OG-card/sitemap endpoints, all `/api/*` mounts (plus `/api/v1/auth` and `/api/v1/reports` aliases), SPA fallback with 30 s 200-entry FIFO TTL-cached Open Graph injection, global error handler (`SystemErrorLog` + email/webhook ops alerts), graceful shutdown, and `startBackgroundJobs()`. Exports `app` with `app.startServer` and `app.startBackgroundJobs`. |
| `cluster.ts` | Production cluster supervisor (`PORT \|\| 5000`). When `NODE_ENV=production` on the primary process, forks one worker per CPU (`os.cpus().length`), restarts exited workers after 1 s, and runs `app.startBackgroundJobs()` **only on the primary** to avoid duplicating cron/interval tasks. In non-production, runs single-process with background jobs inline. |
| `launcher.js` | Detached Node launcher spawning `dist/server.js` on `PORT=5002`, piping stdout/stderr to `server.log`, and writing `server.pid`. |
| `tsconfig.json` | TypeScript compiler config targeting `ES2020` / `commonjs` (`outDir: ./dist`, `strict: false`, `moduleDetection: force`), excluding `dist/`, `__tests__/`, and `*.test.ts`. |
| `start-server.sh`, `run-in-terminal.sh` | Shell helpers for running compiled `dist/server.js` on port `5002`. |
| `check-db.ts`, `query_db.js`, `query_user.ts`, `run-seed.js`, `test-follow.js` | Ad-hoc local database inspection/debug helpers (`run-seed.js` is a legacy wrapper; use `npm run db:seed` for normal seeding). |

## Subdirectories

- [routes/](./routes/README.md) — 40 Express routers covering auth, DJs, mixes, discovery, rankings, bookings, gigs, events/ticketing, payments/PayPal, notifications, onboarding, moderation, and admin.
- [services/](./services/README.md) — Domain services for intelligent notifications, BullMQ queues, Redis SSE pub/sub, timezone scheduling, interaction tracking, smart playlists, and DJ queries.
- [middleware/](./middleware/README.md) — Auth JWT/role guards (`auth.ts`), subscription-tier feature gates (`permissions.ts`), Cloudflare Turnstile verification (`turnstile.ts`), and async route error wrapper (`asyncHandler.ts`).
- [jobs/](./jobs/README.md) — `node-cron` background scheduler (`scheduler.ts`) and batched mix discovery score recalculation (`recalculateDiscoveryScores.ts`).
- [prisma/](./prisma/README.md) — PostgreSQL `schema.prisma`, 25 SQL migrations, database seeding (`seed.ts`), and maintenance scripts.
- [utils/](./utils/README.md) — 41 shared backend helpers for Prisma, Redis/cache, JWT, security/lockout, rate limiting, storage/uploads, image/audio processing, rankings, ticketing QR, email/SMS/push, and subscriptions.
- [__tests__/](./__tests__/README.md) — 24 Jest + Supertest unit, security-hardening, and red-team regression test suites.
- [scripts/](./scripts/README.md) — One-off backfill, seeding, password-rotation, and cleanup operational scripts.
- `uploads/` — Local upload fallback when launched from `app/api/` without S3/R2 or `UPLOADS_DIR` (`utils/storage.ts` defaults to `path.join(process.cwd(), 'uploads')`, organized into `avatars/`, `covers/`, `documents/`, `events/`, `mixes/`, `photos/`, `subscription-proofs/`; `mixes/` is never served statically, and sensitive folders such as mobile-money payment proofs are JWT-gated via `utils/upload.ts`).
- `dist/` — Compiled CommonJS build output generated by `npm run api:build` (mirrors source layout).

## Commands

Run from `app/`:

| Script | Action |
| --- | --- |
| `npm run api:dev` | Run `server.ts` directly via `ts-node`. |
| `npm run api:build` | Compile TypeScript into `app/api/dist/` (`tsc --project tsconfig.json`). |
| `npm run db:generate` / `db:migrate` / `db:push` / `db:seed` / `db:studio` | Prisma client generation, migrations, schema push, seeding, and Studio. |
| `npx jest` | Run backend unit and regression tests in `app/api/__tests__/` (via `app/jest.config.js`). |

## Conventions & Notes

- **API Isolation & Rate Limiting**: All `/api/*` and authenticated responses receive `Cache-Control: no-store, no-cache, must-revalidate, private`. Global `/api` traffic passes through `generalLimiter`; auth, search, uploads, audio streaming, purchases, voting, reporting, and messaging apply stricter per-route limiters.
- **Auth Middleware at Mount vs. Router**: `server.ts` mounts `authMiddleware` globally on `/api/dashboard`, `/api/admin`, `/api/messages`, `/api/support`, and `/api/opportunities`. Other routers apply `authMiddleware`, `softAuthMiddleware` (optional JWT parsing for personalized public responses), or `requireRole` per route.
- **Observability, Probes & Social Previews**: `/health` verifies PostgreSQL (`SELECT 1`) and returns cache stats; `/health/readiness` requires both PostgreSQL and Redis; `/metrics` serves Prometheus metrics restricted to loopback IPs or `Authorization: Bearer <METRICS_TOKEN>`; `/og` renders Open Graph preview metadata for shared links. URL `?token=` values are redacted from logs via `redactUrlToken`.
- **Single-Run Background Jobs**: Always start production via `cluster.ts` (or a single `server.ts` process) so `startBackgroundJobs()` runs once and avoids duplicate cron executions and trial/bug-report notifications.
